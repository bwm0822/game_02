# 部位（tools/part）

`part.json`（部位 pool）的總覽與整理：一次看到全部條目、誰在用、哪些壞了，做改名／改 kind／換圖／新增／複製／刪除。開法：`npm run dev` 後開 `/tools/` 的「部位」分頁（殼見 [tools-shell.md](tools-shell.md)）。

**擺放也能在這裡調**：詳細裡的 `scale/x/y/a/ox/oy` 數字欄（女＝右欄切到女，`scale/x/y` 改 `f`），身體條目另有 neck／wristF／wristB 支點表＋右欄十字（要在預覽的「顯示 ▾」勾才畫、才能拖，跟試穿共用勾選），改了立刻寫檔，有 undo（見下）；試穿也能調（見 [fit-tool.md](fit-tool.md)）；從圖產生新條目走紙娃娃「存到 pool…」（見 [paperdoll-tool.md](paperdoll-tool.md)）。

## 畫面

三欄，沒有 header（這頁沒有存檔／undo）：

- **中間欄**跟右欄之間也有把手（`data-resize`，記在 `tools.mid.part`，右欄最少 300px；沒選條目右欄空的時候把手藏起來，見 [tools-shell.md](tools-shell.md)）。
- **左欄**（`splitter.js` 可拖寬度，記在 `tools.left.part`）：
  - 上面：搜尋（名稱、id 或 sprite）、篩選 全部／未使用／壞的（附數量）。篩選跟搜尋同時套在樹和縮圖總覽。
  - 樹：照 `ROLE_PARTS` 的順序分組（身體／鞋子／衣服／頭／頭髮／手），kind 不認識的另一組「不認識的 kind」。收合用 `fold.js`（預設全摺、Alt＋點全部、記在 `tools.part.open`、搜尋中全開），規則同道具編輯器：摺起選到的那組就取消選取，從別處選到（總覽卡片、新增、改名、↗ 跳過來）就展開那組。每列 20px 圖示＋id＋使用次數（hover 看是誰），沒人用的整列變灰，壞的加 ⚠（hover 看原因）。再點一次選到的列＝取消選取。
  - 下面：「＋ 新增」、狀態文字。
- **中間**：
  - 沒選＝**縮圖總覽**：上方一排部位分頁 `全部｜身體｜鞋子｜衣服｜頭｜頭髮｜手｜不認識的 kind`（附篩選／搜尋後的數量，0 的不列，但目前分頁空了也留著；記在 `localStorage` 的 `tools.part.tab`）；「全部」照同樣的組分段（有分段標題），其他一次只列一個部位，卡片畫原圖（不套 scale/x/y，等比縮進 64×64）＋id，右上是在用的角色數，沒人用標灰、壞的紅框；點卡片＝選取。
  - 選了＝**詳細**：標題列（大 id、kind、動作：↗ 到試穿調、改名…、改 kind…、換圖…、複製…、刪除…）、問題清單、原圖（160px）、**擺放**數字欄（`scale` 前面一條**透明度滑桿**：只調右欄合成裡選中的部件（選身體就是身體自己，帽子後片一起），人偶身體跟支點十字不變；照 kind 記在記憶體（`S.alpha`），換條目保留、男女共用、重整回 100%，不寫檔、不進 undo、不跟試穿同步，拖的時候只重畫預覽（`preview.js` 的 `opt.alpha(k)`＋`redrawAll()`）；JSON 模式跟著藏但照樣套用。`scale/x/y/a/ox/oy`，placeholder＝預設值或女版時的基準值，空白 ↑↓ 從 placeholder 起跳，步進看 `tools/settings.json`（設定分頁改了即時換，`ST.onChange`→`applySteps()`，數字欄帶 `data-step`，不重畫）；清空＝刪 key；右欄切到女時表頭標 `x（f）`、改 `f`，第一次改從基準複製 scale/x/y 建出 `f`，有 `f` 時有「刪除女版」）、**身體條目的支點表**（neck／wristF／wristB 的 x/y/a，規則同試穿的支點表：不分男女寫基準（不放 `f`）、只填 x 補 y、清空 x 或 y＝刪掉整個支點、清空 a 只刪 a；`setPivot()`）、其他欄位（唯讀，`kind`、擺放、身體的支點、`f` 以外全列，物件印 JSON）、使用者（每個角色一列＋↗ 跳角色分頁）。
- **右欄**（固定寬度，沒選時藏起來）：**套在人偶上的合成**，最下面 `男｜女` 切換（記在 `localStorage` 的 `tools.part.sex`，換條目保留）。只有畫布那層（`preview.js` 包的 `.cvbox`）會捲，預覽的選項列跟男女固定在右欄下方，放大到 ×6 也點得到；右欄最寬 50vw。重用角色編輯器的 `preview.js`，人偶＝人形範本尺寸（32×64、錨點 y 16）＋`body-man`／`body-woman`，條目自己是 body 就換掉身體；女＝`sex: 'f'`，照遊戲 `partFor()` 有 `f` 就套（標「用女版 f」），沒有就用基準數字（標「沒有 f，用基準數字」）。用來一眼看出擺歪（部件本身不能在畫布上拖，數字在中間欄改，要整套一起看用試穿）。選的是**身體**時沒有男女切換（男女各有自己的身體條目；`sexFor()` 一律當男，數字欄不標 `f`、只寫基準），右欄只畫它自己（標題「身體 <id>」）＋三個支點十字（`previewEl(..., {pivots})`，只有部位分頁傳；粉＝脖子、青＝前手腕、橘＝後手腕，畫法同試穿 `handles.js` 的 `drawCross()`）：拖十字改位置、拖十字上方白點轉 `a`（Shift 吸 15°、旋轉游標），滑過變粗；拖的時候只改記憶體重畫，放開才寫一次檔（一筆 undo）；支點不分男女寫基準。底色可換（見下）。
- **未使用**：沒有角色的部位欄位指到它。只標示，不擋任何操作、沒有一鍵清除——路人隨機長相做出來之後，沒有角色在用不代表沒用。
- **帽子**（`kind: 'hat'`）：詳細多一格「藏頭髮」（`hideHair`，勾了立刻寫、取消刪 key，走條目 undo）；有 `back` 時原圖下面多畫後片。改名只改 id、刪除不碰 PNG，所以 `-front`／`-back` 不用另外處理。
- **壞的**（`problems()`）：sprite 或 `back` 在 textures.json 找不到（含格子編號超出範圍，`IC.check()`）、kind 不在 `ROLE_PARTS` 裡、**放錯欄位**（有角色的 `hair` 指到 kind 是 `head` 的條目之類）。角色指到不存在的部位 id 是角色編輯器的檢查，這裡不重複。
- **合成底色**：`preview.js` 的選項列有顏色選擇器＋「棋盤格」（同試穿的 UI），選了純色就不畫棋盤格；同頁所有預覽一起換，記在 `localStorage` 的 `tools.preview.bg`（跟試穿的 `tools.fit.bg` 分開記）。角色編輯器的預覽也有。

## 動作（立刻寫檔＋廣播）

每個動作都直接寫 `part.json`（`notifySaved`），危險的先確認。別的分頁存了 `part.json`／`role.json` 這裡就重讀（這頁沒有未存狀態）。

- **名稱**（`name`，選填）：只給工具看，遊戲不讀、不翻譯；可重複，id 才是識別。在詳細區的名稱欄改（JSON 模式藏起來，直接改 JSON），失焦或 Enter 寫檔、走條目 undo，清空＝刪 key；打字中別的分頁存檔不重畫，改完直接點別的列也不會跳回來。有名稱時左樹、詳細標題是「名稱＋灰色 id」，總覽卡片、角色編輯器選圖器只顯示名稱（id 看滑過提示），試穿下拉是「名稱（id）」，沒填都只顯示 id（`PT.nameOf()`）；搜尋也比對名稱；複製照抄；紙娃娃重存保留。

- **限定**（`sex`：`m`／`f`，沒寫＝男女都能用，遊戲 `equip.js` 的 `sexOk()`）：詳細區原圖下面的下拉，選 `—`＝刪 key；走 `edit()` 一樣立刻寫＋條目 undo。改成限某性別時，有性別不符的角色在用就擋（`setPartSex()`，同改 kind），`problems()` 也會列「X 在用，但這條限女」。有 `sex` 的條目：右欄合成固定那個性別、另一顆鈕按不了，擺放數字寫基準（`writesF()`，遊戲不套 `f`），縮圖左上標 ♂／♀。
- **擺放數字**：改一格（change）就寫一次。每次都先從磁碟讀最新的 `part.json`、只改那一筆再寫回（別的分頁剛存的不會被蓋掉），動作排隊（`enqueue`）不會互蓋。只有擺放跟整筆 JSON 有 **undo／redo**（左下 ↶ ↷、Ctrl+Z／Ctrl+Y／Ctrl+Shift+Z，文字欄裡留給瀏覽器），記的是條目層級的改前／改後（`S.hist`），undo 也是讀最新的再把那一筆換回去、立刻寫；改名會把紀錄裡的 id 跟著換，刪除就拿掉那筆的紀錄。其他動作（改名、刪除…）不進 undo。

- **改名**：共用 `tools/common/part.js` 的 `askRename()`／`rename()`（角色編輯器的選圖器右鍵也是同一份）。新 id 只能英數字／底線／減號、不能撞名；第二個確認框列出要一起改的角色，以及 `src/`、`tools/`、`scripts/` 裡寫死這個 id 的行（只列不改，例如角色範本的 `body-man`；要有專案根目錄才掃）。`part.json` 換 key（位置不變），再讀 `role.json` 把部位欄位的引用換掉直接寫檔。
  - 改名前先廣播 `partRenamed`（`shell.js` 的 `notifyPartRenamed()`）：**角色分頁、試穿分頁有未存修改的話，先在記憶體跟著改**（角色分頁改引用；試穿改 `part.json` 的 key 跟 `role.json` 引用），之後它們存檔做角色／條目層級三方合併時，兩邊都改過的那筆以自己的為準，而自己的已經是新 id，所以不會被舊 id 蓋回去、也不會讓舊 key 復活。沒有未存修改的分頁照常因為存檔通知重讀。
- **改 kind**：有角色在用就擋（列出是誰），不然選一個 kind 寫回。改 kind 跟刪除只處理改名這種跨檔情況，其他分頁未存的同一條目修改，存檔合併時會照一般規則以那邊為準。
- **換圖**：icon 選圖器（`IC.pickIcon()`，可選 `sheet:格子`／`atlas:frame`）改 `sprite`，擺放不動。
- **新增**：對話框填 id、kind、圖（選圖器）；選圖時 id 還沒手動改過就自動帶 `sprite`（`:` 換成 `-`，撞名接 `-2`…）。數字抄同 kind 第一筆條目的 `scale/x/y`（沒有就不寫），排在同 kind 最後一筆後面，建好選到它。給怪物／動物這種 sheet 格子當身體的條目用（紙娃娃只會產生 `roles/parts/<id>.png`）。
- **複製**：同一個對話框，預設 id `<原 id>-2`、kind／圖帶原本的，整筆照抄（含 `f`），排在原本後面（kind 改了就排到那個 kind 最後）。
- **刪除**：有角色在用就擋；PNG 不刪（到「圖片」分頁搬到 .tbd）。
- **JSON**（標題列第一顆，開啟時顯示「表單」）：藏頭髮／限定／擺放／支點／其他欄位換成一個整筆 JSON 框（`jsonedit.js`），標題列、問題清單、原圖、使用者留著；模式記在頁面、換條目保持，重整回表單。id 不在框裡（走「改名…」）；條目位置不動。失焦時 `applyJson()` 讀磁碟最新版，通過就整筆換掉、立刻寫檔，走條目 undo；清空框＝`{}`（標壞的，undo 救回）。
  - **留草稿不寫檔**：語法錯、非物件（`jsonedit.js` 的檢查）；有角色在用卻改 kind、性別不符卻改 sex（`jsonBlocked()`，規則同按鈕，沒改這兩個 key 就不檢查）；開始編輯後這筆被別的分頁改過（比對 `base`，多一顆「覆蓋」）。sprite 打錯、kind 不認識這類不擋，寫檔後進問題清單。
  - **草稿**（`S.drafts[pid]`）：只在記憶體、按條目分開，切走不擋，左樹標 ✎、表單模式的鈕顯示 `JSON ✎`，「捨棄草稿」回檔案內容；改名跟著換 id（別的分頁改的走 `onPartRenamed`），條目沒了就清掉。
  - **不重畫**：框有焦點時 `render()` 只記 `S.stale`，離開框才補畫（別的分頁存檔不會吃掉打到一半的字）；按住滑鼠時也等放開（`released()`），不然 blur 觸發的重畫會換掉按鈕或列、click 落空。
- **↗ 到試穿調**：找第一個用到它的紙娃娃型角色（有 `head`、`handF` 或 `handB`，試穿只列這種），`gotoTab('fit', [角色, kind])`；試穿選那個角色、切到擺放分頁、游標放在那個部位的第一個數字欄。沒有紙娃娃型角色在用就停用。
