# 試穿（tools/fit）

選角色、穿上裝備，用數字調整角色部件跟裝備疊在身上的擺放（「擺放」分頁）；「動畫」分頁編 `anim.json` 的武器動畫（下劈、橫掃、瞄準…）。開法：`npm run dev` 後開 `/tools/` 的「試穿」分頁（殼見 [tools-shell.md](tools-shell.md)）。

## 範圍

- **角色**：只列紙娃娃型（有 `head`、`handF` 或 `handB` 的），左欄是跟角色分頁一樣的 `kind` ▸ 子分類 `grp` 兩層樹（`role/schema.js` 的 `roleTree()`＋`common/views.js` 的 `treeEls()`，兩邊共用；子分類順序照全部角色算），只看不改：沒有右鍵、不能拖，子分類在角色分頁管理（見 [role-editor.md](role-editor.md)）；收合狀態記在試穿自己的 localStorage。部位（`body`／`head`…）是 `part.json` 的 id。
- **五格**：武器／頭盔／護甲／手套／靴子，畫成跟遊戲裝備欄一樣的圖形格（空格是遊戲 `CAT2ICON` 的剪影）。點格子＝選中（金框）＋跳出挑選視窗，視窗列同 `cat` 且有 `equip` 的道具 icon＋名稱（沒有 `equip` 的道具穿上也看不到，所以不列），第一格是「卸下」，點了就穿上並關窗，點窗外／Esc 不改；格子下方只顯示選中格的道具名稱＋擺放數字。**換角色裝備不動**（選中格也不動；重新讀取／別的分頁存檔重讀也保留，只清掉道具已不存在或沒有 `equip` 的格子），一開始五格是空的；五格旁的「穿原裝」把五格整組換成這個角色的 `inv.equips`（原裝沒有的格子清空，沒有原裝時反灰）。換裝只是試穿，**不會寫回** `inv.equips`（要改穿搭用角色編輯器）。
- **右鍵格子**＝只選中（金框、下方換成那格的數字），不開挑選視窗。
- **透明度**：擺放分頁每格正下方一條滑桿（0～100%，數值在 tooltip），每格各自一個（`S.alpha`），只影響預覽（兩個分頁都套，動畫殘影＝30%×武器透明度）、不存檔不進 undo，換角色、換件都保留。藏部位照舊，透明的頭盔一樣藏頭髮。「角色部件」表每列最前面也有一條（key＝部位 kind，同一個 `S.alpha`，規則一樣；後片跟著主圖；部位選「（無）」反灰，被裝備隱藏的照常能拖）。
- **挑部位**：「角色部件」表八列（身體／鞋子／衣服／頭／頭髮／帽子／前手／後手）各一個下拉，列 `part.json` 同 kind 的條目＋「（無）」，選了寫 `role.json` 的那個欄位（id，「（無）」刪 key），跟數字一起 undo。新條目從紙娃娃「存到 pool…」或部位分頁來；部位分頁的「↗ 到試穿調」送 goto `[角色, kind]`，這裡選角色、切擺放分頁、游標放到那個部位的數字欄。部位分頁改名時這裡有未存修改的話，先在記憶體把 `part.json` 的 key 跟 `role.json` 的引用改掉（見 [part-tool.md](part-tool.md)）。
- **可調**（只用數字欄，畫布只負責預覽）：
  - 部位條目（`part.json`）的 `scale/x/y/a/ox/oy`。**部位擺放是全角色共用的**，用到同一個條目的角色都會一起變（名稱後面標「共用 N 個角色」，hover 看是誰）；左欄用到改過條目的角色也標 ●。女角的 `scale/x/y` 改 `f`，規則同下面的裝備（`sexCells()` 兩邊共用）
  - 「頭」列名稱旁的 🔗（預設關，記 localStorage `tools.fit.headLink`，不進 undo）：開著時改頭的 `scale/x/y/a`，頭髮跟著動（`linkHair()`，單向）；頭髮列的 `scale/x/y/a` 鎖住不能改（`sexCells(…, lock)`，hover 有提示），`ox/oy` 跟頭髮下拉照常。用改前／改後**實際生效**的值（`partFor()`，女角套過 `f`）算差：`x/y/a` 加一樣的差、`scale` 乘一樣的倍率且頭髮對頭的 x/y 偏移跟著縮（以頭的 x/y 為中心），`ox/oy` 不連動；清空回預設也算差，頭髮寫成數字。頭髮照自己的規則寫（有限定 `sex` 或男角＝基準，女角＝`f`、第一次從基準複製），`a` 一律基準；頭＋頭髮同一次 `commit()` 一筆 undo；頭髮被裝備藏住或共用給別的角色照樣改，沒頭髮就不做事
  - 裝備 `equip` 的 `scale/x/y/a/ox/oy` → `item.json`。**裝備擺放是全角色共用的**，在這個角色身上調準了，換別的角色可能會歪
  - 女角（`role.json` 的 `sex` 不是 `m`，目前只有 `f`）：裝備的 `scale/x/y` 數字欄改的是 `equip.f`（表頭標 `scale（f）`，`a/ox/oy` 還是基準），沒有 `equip.f` 時顯示共用值當 placeholder，第一次改就從基準複製 scale/x/y 建出 `equip.f`（`sexCells()`）；有 `equip.f` 時旁邊有「刪除女版」回到共用。道具／部位有限定 `sex`（`sexOk()`）時遊戲不套 `f`，數字一律改基準（`sexCells(…, only)`，表頭不標 f、不給刪除女版、註明「限女：基準」）。裝備格的挑選視窗跟部位下拉只列 sex 符合角色的，目前穿著／用著不符的保留、標 ⚠（部位列跟裝備名旁邊也有 `.sexwarn`）。預覽、武器動畫的 rest 都照 `equipFor()`／`partFor()`（`src/core/equip.js`，跟遊戲同一支）
  - 裝備 `equip.hideHair`（「藏頭髮」勾選框）：穿著任一件有它的裝備時遊戲不畫頭髮；另外穿任何護甲不畫衣服、穿任何靴子不畫鞋子、戴任何手套不畫兩隻手（`hiddenParts()`，跟遊戲同一支），被藏的部位那列標「目前被裝備隱藏」；要調先卸下該裝備
  - **支點**（部件表下面的「支點」表）：body 條目的 `neck`／`wristF`／`wristB` 的 x/y/a（`a`＝靜止角度，掛在上面的繞支點轉；**不分男女都寫基準**，不放 `f`：男女各有自己的身體條目 `body-man`／`body-woman`，支點跟著身體走），只填一格會補上另一格目前值、清空 x 或 y＝刪掉整個支點、清空 a 只刪 a；擺放分頁畫布上是三個十字（粉＝脖子、青＝前手腕、橘＝後手腕，照 a 轉、往上那條較長）可以拖位置（放開記一筆 undo，a 保留），十字往上的白點（虛線連著）是旋轉把手，拖它改 `a`（Shift 吸 15°，a 轉回 0 就刪 key；還沒有這個支點時連目前位置一起寫），滑鼠滑過（或拖著）的十字和把手變粗、游標在十字上是 move、在白點上是左右旋轉箭頭（`ROT_CURSOR`，內嵌 SVG，載不到退回 grab）。掛在支點上的部位、裝備（頭、頭髮、頭盔、武器、前後手、手套）數字**相對支點**，移支點整組跟著走（同一把武器換到不同身體會黏在各自的手腕上）
  - **武器的手腕位移**（武器格有武器時支點表多三欄「武器 x｜y｜a」，前／後手腕兩列可填、脖子留空，跟現在選哪一格裝備無關；武器格空的時候沒有這三欄）：`item.json` 的 `equip.wristF`／`equip.wristB` `{x, y, a}` 是疊在 body 支點上的**位移**（x/y/a 相加，如弓把前手往前伸、後手收到胸前），只寫在 `equip` 最上層、男女共用（不放 `f`，女角改也寫這裡）；只有武器（`CAT_WEAPON`）的會生效，採集暫拿工具（`hold()`）期間改用工具自己的（沒寫＝0）。規則在 `src/core/equip.js` 的 `pivotOf(body, k, held)`（`held`＝手上那把的 equip，`weaponOf(items, cat)` 找穿著的武器），遊戲 `RoleView._placeWrists()`、角色面板、角色編輯器／試穿預覽共用；遊戲換裝時節點瞬間跳過去，正在播動畫就只換 `node.pivot`、收回時（`pose.js` 的 `setRest()`）回到新位置。支點表上面「拖十字改：身體｜武器」（預設身體、不記住，武器格空的時候不能切）：切到武器時拖青／橘十字（含白點轉角度）改的是武器的位移（十字畫在 body＋位移的實際位置）、粉色脖子變淡拖不動；支點表的 x/y/a 永遠是 body 的、武器欄才是位移。紙娃娃存讀 item 不算這個位移（畫布是空手的人偶，武器相對手的擺放照空手存，進遊戲手跟武器一起被位移帶走）
  - **畫布上的部件／裝備不能拖也不能點選**（擺放分頁）：滑鼠只對支點十字有反應，部件／裝備滑過不畫框、游標不變、點了不選、點空白也不取消選取；擺放一律用中間欄的數字調。選取在中間欄（`S.pick`＝部位 kind 或裝備 cat）：點裝備格＝選那格（`S.cur`），部件表那列有焦點＝選它（那列反白，`pickQuiet()` 只重畫預覽）
  - 欄位清空＝刪 key（遊戲用預設值，placeholder 顯示預設值）；不是數字的不寫
- 不做：改 sprite（用道具編輯器、紙娃娃存到 pool）、改像素（用紙娃娃）、跨角色比對、`ext` 的獨立擺放（跟主圖同一組數字，跟遊戲一樣）。

## 預覽

合成規則同角色編輯器的 `role/preview.js`（也就是 `RoleView._addPart`）：部件在 view 中心 +rig（body 的 x/y/a）+(x, y)、origin `(ox ?? 0.5, oy ?? 1)`、掛在支點上的先用 `atPivot()` 加回 body 的支點（試穿整張畫布套 rig 變換、內部都是 rig 座標，身體圖畫在 rig 的 0,0；角色預覽用 `flatPart()` 直接換成 shape 座標），依 `DEPTH` 疊（`DEPTH` 是遊戲 `flatDepth()` 攤成一層的值：節點整組的 depth＋節點裡的 depth/100；手套後片用 `BACK_DEPTH`）。「顯示（N）▾」下拉（`tools/common/showmenu.js`，點開跳面板、點外面收起）多選虛線 view、黃十字錨點、物理 b／佔格 g／互動 z 框、脖子／前手腕／後手腕支點十字，預設全不勾，記在 `localStorage` 的 `tools.preview.show`（跟角色／部位分頁的預覽共用，別的分頁改了用 `storage` 事件跟著換）；沒勾的支點不畫也拖不動，動畫分頁三個支點反灰；翻面另外勾。

中間欄跟右欄之間有把手（`splitter.js` 的 `data-resize`）：拖了中間固定寬度、右欄吃剩下（最少 340px），雙擊回自動，記在 `tools.mid.fit`。右欄分上下兩塊：上面畫布鋪滿（不捲），下面控制面板（顯示選項、頭／頭髮、倍率、動畫列）固定在底部一直看得到，兩個分頁共用。縮放平移同道具／部位／角色的預覽（`tools/common/panzoom.js`，見 [role-editor.md](role-editor.md)）：滾輪以游標為中心 ×1.2、按住中鍵拖曳平移，view 記在 `tools.preview.view.fit`，換角色／分頁／重繪都不動，「置中」把原點放回中央、倍率剛好裝下 view 框加一圈（動畫分頁那圈大一點）；畫布的 hit-test 用 `geo.vc`＝原點在畫布上的位置換成世界單位，拖曳只認左鍵、平移中不 hover。頭／頭髮勾選（`tools/common/headhide.js`）只影響畫，支點照樣能拖。

倍率是輸入框（0.1～20，可打小數、超出夾邊界），↑↓ 跟原生上下三角形都吸格子（<1 每 0.1、1～6 每 1、再上去 8／10／12／16／20；三角形的 input 事件沒有 `inputType`，靠這個跟打字分開）；「遊戲」按鈕填入 `min(螢幕寬/1024, 螢幕高/768)`（取兩位小數）：遊戲畫面固定 1024×768、`Scale.FIT` 塞進視窗、鏡頭沒 zoom，所以這是全螢幕玩時的大小（視窗越小遊戲裡越小），填完就是普通數字。canvas 照 `devicePixelRatio` 開；零件用雙線性（`imageSmoothingEnabled`）畫，跟遊戲 Phaser 預設 LINEAR 一樣，所以大倍率會糊。背景預設棋盤格，色塊可改純色（記在 localStorage `tools.fit.bg`）、「棋盤格」按鈕改回。

## 武器動畫（anim.json）

`public/assets/json/anim.json` 是**手寫來源檔**（沒有轉檔），全武器共用的具名動畫：

```json
"chop": {"follow": false, "pivot": {"x": -13, "y": 12}, "ready": 120, "hit": 200, "back": 150, "hold": false,
         "keys": [{"t": 120, "x": -13, "y": 6, "a": -90, "ease": "Quad.Out"},
                  {"t": 200, "x": -7.8, "y": 15, "a": 75, "ease": "Cubic.In", "path": "arc"}]}
```

- 動的是 **拿武器那隻手的手腕節點**（看不見的子 container）：武器 `equip.hand` 沒寫＝前手腕 `wristF`、`"B"`＝後手腕 `wristB`（如弓；`equip.js` 的 `handOf()`），空手＝前手，掛在上面的手、武器（含暫拿的工具，也照它的 `hand`）、手套一起動，所以空手也能播（揮拳）；靜止＝body 的那個支點＋武器的手腕位移、角度＝它的 `a`（影格是絕對姿勢、前後手共用同一份動畫，只有收回回到靜止角度）。後手的武器畫在身體後面（`wristB` 節點整組 -1，節點裡武器 4＜手 5，後手蓋住握把；工具預覽的攤平 depth 是 `role/schema.js` 的 `depthOf()`）。
- 影格 `x/y`＝手腕在 rig 本地座標（面向右、相對 rig＝body 的 x/y/a，人形 body 都是 `y:32`＝腳底）的**絕對位置**，`a`＝手腕角度（武器實際角度＝手腕角度＋武器自己的 `equip.a`）；`t` 是從開始算的 ms，`ease` 是進入這格的緩動（`pose.js` 的 `EASE`），`path:'arc'` 繞 `pivot` 做極座標補間（方向跟角度變化同向），預設直線。
- 第 0 格隱含＝當下姿勢，最後自動補一格用 `back` ms（`Quad.Out`）收回靜止；這兩段走最短角度，中間影格照數字 lerp（-90→90 就是順時針掃 180°）。
- `follow:true`：以「目標在正右方」來擺，播放時整組繞 `pivot` 轉到目標方向（瞄準、橫掃）；`false` 只跟著 `face()` 翻面。
- `ready`：播到這裡停住，等程式做身體位移（普攻／橫掃前撲、衝刺）；`hit`：命中／放箭時刻（沒寫＝最後一格）；`hold:true`：播完最後一格停住等 `anim_end()`（遠程舉著等箭命中）。
- 遊戲端：`COM_Anim` 的 `root.anim_play(id, pt, {ready})` 回傳的 Promise 在 hit 時 resolve（`true`＝有播），`root.anim_end()` 收回 hold；`view.wrist` 是要動的手腕節點（`_updateEquips()` 照武器／暫拿工具的 `hand` 記在 `view._hand`；裡面空的＝動物、沒手沒武器就不播，直接跑 `ready`）。用哪個動畫：普攻看武器的 `anim`（`item.json` 最上層，如匕首 `stab`；`com_stats.js` 帶進 `total.anim`）；技能看技能的 `anim`（`ability.json`），近戰／遠程型（`travel.type` 是 `melee`/`ranged`）技能沒寫就退回武器的 `anim`；都沒寫的預設：近戰 `chop`、ARC `sweep`、衝刺 `chop`、遠程 `aim`（`com_action.js`；普攻的規則是 `pose.js` 的 `weaponAnim(item)`＝`anim ?? DEFAULT_ANIM[近戰／遠程]`，試穿也用它）。
- 數學在 `src/core/pose.js`（純函式、不碰 Phaser）：`animTrack()` 攤影格、`poseAt()` 取某 ms 的姿勢；遊戲用 tween 推時間、工具用滑桿推，兩邊一樣；**改動畫數學改 pose.js，不要在 com_anim.js 另寫一份**。

## 動畫分頁

- 上方選武器（同五格），武器的擺放數字也在這（調 `ox/oy` 對握把）；換武器（含選角色帶入原裝）時照遊戲規則 `weaponAnim()` 自動切動畫（有寫 `anim` 用它，沒寫遠程 `aim`／近戰 `chop`）；空手或 `anim` 指到不存在的動畫切到「（無）」（後者狀態列提示）。動畫下拉第一個是「（無）」：選到時隱藏參數／影格表／時間軸，只顯示靜止角色。新增／複製／刪除，名稱欄直接改名（英數字底線）：改名連帶改 `item.json` 裡引用它的 `anim`、刪除連帶清掉（同一筆 undo），刪除後停在（無）；技能 `anim` 跟 `DEFAULT_ANIM` 預設只提示、要自己改。
- 屬性：轉向目標、舉著等、支點 x/y、ready、hit、back；影格表 `t/x/y/a/ease/path`，點列＝選中並跳到那一格，再點一次（或 ◆、Esc）取消選取；「新增影格」跟播放頭無關，只看選取：選了 #i 插在它跟前一格（或 0）的正中間，沒選接在最後一格 `+ back/2`（沒 back 就 +100），姿勢都取該時間的補間，插完選中新格；中間塞不下（差 1ms）只提示不插。
- 畫布：拖手腕上的東西（前手／武器／手套，或手腕點附近）＝移選中影格的位置、拖白點（旋轉把手，手腕本地往上 16）＝轉角度（Shift 吸 15°）、拖藍點＝支點；只能改選中的影格。虛線＝手腕軌跡，半透明＝其他影格（整組手腕上的東西）。前手腕上沒東西時不能預覽。拖拉中直接改資料、放開才記一筆 undo。`follow` 動畫轉了向也能拖（位移會反轉回影格座標）。
- 時間軸：◆ 影格、R ready、H hit 都能拖（影格夾在前後格之間、R/H 不超過最後一格），灰底是收回段；點空白跳時間，滑桿靠近影格會吸附。`▶ 播放` 時 ready 停 100ms、hold 停 300ms 模擬遊戲裡等程式的時間。
- 目標角度：0＝右、90＝下、180＝左。面向跟遊戲的 `face()` 一樣跟著目標翻，動畫分頁「翻面」反灰。

## 存讀檔

不走 `common/doc.js`（它一頁只管一個檔），自己管四份（`role.json`、`part.json`、`item.json`、`anim.json`）：

- undo／redo 一筆記四個檔的快照（Ctrl+Z／Ctrl+Y，最多 300 步）。
- 存檔（Ctrl+S）只寫有改的檔；寫之前比對硬碟，被別人改過就問「合併／覆蓋／取消」（`merge3`，同 `doc.js`），寫完 `notifySaved()` 廣播。
- 收到別的分頁存檔：那個檔沒改過就重讀（undo 紀錄從現在重算），有改就只提示、存檔時合併。`textures.json` 更新時重畫預覽。
- 換角色時修改留著，一起存；未存狀態回報給殼（分頁 ●、關頁警告）。
