# 提示詞（tools/prompt/）

殼的「提示詞」分頁。管理給 AI 生圖（裝備、道具…）用的提示詞，組好按「複製提示詞」貼到外面的 AI，**不打 API**。物品完全手動建，跟 `item.json` 無關。

## 檔案

- 頂端「檔案」框：相對專案根目錄的路徑，預設 `prompts/prompt.json`，記在 `localStorage` 的 `tools.prompt.path`；按「載入」或 Enter 換檔。
- 檔案不存在時問要不要建骨架（資料夾一起建）。
- 結構：

```json
{
  "items": { "武器": [], "武器/劍": [ { "name": "鐵劍", "file": "sword-iron", "desc": "...", "common": "武器" } ], "護具": [], "道具": [] },
  "common": { "武器": "...", "護具": "...", "道具": "..." }
}
```

`items` 的 key 是**分類路徑**（`/` 分層，層數不限，分類名稱不能有 `/`），每個分類可同時有子分類跟直屬物品。載入跟每次改結構都正規化（`normItems()`）：補齊祖先（沒有直屬物品存 `[]`）、key 照樹的前序排（兄弟照第一次出現的順序），所以檔案順序＝畫面順序；手寫檔缺祖先不報錯、下次存檔補上。分類跟 common 名稱可自由增刪改名（中文 OK），common 不必跟分類一對一。`file` 是生圖要存成的檔名（不含副檔名，照 texture key 命名，如 `sword-iron`；護具是整套的基本名，部位後綴由紙娃娃加），網頁版 ChatGPT 不能指定下載檔名，所以範本裡請它用 Python 另存。

## 組合規則（`compose()`）

common 跟 desc 先各自去註解（`strip()`）：`//` 到行尾是註解，緊貼在 `:` 後面的（`https://`）不算；去完只剩空白的行整行拿掉，其他行去行尾空白，原本就空的行保留。然後 common 裡有 `{desc}`／`{name}`／`{file}` 就代換；沒有就是 `desc + '\n' + common`（空的那邊省略）。`file` 沒填時，common 裡含 `{file}` 的行整行拿掉。搜尋照舊比對整段（註解也搜得到）。

desc／common 框是 `commentArea()`：textarea 文字透明、底下疊同字型的 `pre` 把註解畫灰；高度跟著內容長（沒有捲軸，換行才對得齊，寬度變了由 `ResizeObserver` 重算）。`Ctrl+/` 切換游標行／選取行的行首 `// `（非空行全是註解就拿掉、否則全加，空行跳過），用 `insertText` 一次換掉，textarea 原生 undo 一步、離開欄位才進工具的 undo。

## 畫面

- 左欄同一條清單：最上面是「⚙ 共用」組（標題 ＋ 新增共用，這組不能改名／刪除／拖進物品），下面接分類樹（每層縮排，同一層**子分類在前、直屬物品在後**，標題數字是整棵子樹的物品數）；每組預設摺起來、點標題展開／摺疊，各層各自記，Alt＋點分類＝連整棵子樹一起摺／展開、Alt＋點共用組＝所有組一起（展開的組記在 `localStorage` 的 `tools.prompt.open`，不分提示詞檔；搜尋中全展開；摺起的分類含選到的物品會清除選擇）；底部按鈕是「＋ 新分類」（頂層）；每列只顯示名稱（描述／內容不上清單）；搜尋同時篩物品跟共用（比對名稱跟描述／內容），分類只留有命中物品的路徑（連祖先），分類名稱命中就留整棵子樹。選到哪種，右欄就顯示哪種（`S.mode`），再點一次選到的就取消選擇。
- 分類：標題 ＋ 新增物品（`common` 預設從最深一層往上找第一個同名的 common，`武器/劍` 有 `劍` 用 `劍`、沒有退回 `武器`）、⊞ 新增子分類、✕ 刪除（連整棵子樹，非空要確認並列出子分類／物品數）、雙擊改名（只改這一段，子路徑前綴、選擇、摺疊跟著換）；標題可拖曳（`moveCat()`），放在目標標題上 1/4＝插到前面當兄弟、中間＝當它的最後一個子分類、下 1/4＝插到它的子樹後面當兄弟，整棵子樹一起搬，不能拖進自己的子孫、撞名擋下。
- 物品：物品可拖曳排序、可拖到任何一層的分類（拖到分類標題＝放最後）；搜尋比對 name／desc。
- 物品多選（分類不能多選）：Ctrl＋點加減、Shift＋點從起點（最後單選的那個，`S.sel`）選到這裡，照清單看得到的順序、可跨分類（`S.picks`，剩一個就退回單選；摺起分類會清掉裡面的）；多選中一般點一下＝只選那個。拖選到的其中一個＝整批照畫面順序緊挨著插在目標前面（`moveItems()`，目標本身被選到就往後找第一個沒被選的），搬完維持多選。右欄換成批次面板：已選清單（點了單選它）、共用下拉（「（不變）」以外的選項一次套到全部）、取消選取、刪除。右欄 名稱、檔名（後面標 `.png`＋「複製檔名」複製 `file`（不含副檔名），空的停用；搜尋也比對）、共用下拉、描述、組合結果＋複製＋「複製存檔指令」（`saveCmd(file)`，寫死的一句「把剛剛那張圖用 Python 原樣存成 `<file>`.png…給我下載連結」：網頁版 ChatGPT 同一輪生完圖 Python 拿不到圖，要圖出來後下一輪再貼這句；沒填 file 停用，不檢查透明度）；名稱／檔名／描述打字時組合結果即時更新，離開欄位才進 undo。
- 共用：右欄 名稱（改名連物品引用一起改，同一步 undo）、內容、用到的物品（點了跳過去）。刪除不擋，用到的物品清單標 ⚠、下拉顯示「（遺失）」。

## 存檔

手動存（Ctrl+S）、undo/redo、殼分頁圓點、`BroadcastChannel` 廣播 `file`＝路徑。存前發現檔案被外部改過就三方合併（`obj.js` 的 `merge3`）：物品沒有 id，**以分類路徑為單位**（合併完再正規化）；common 以每一條為單位。已知限制：這邊改名／搬了父分類、外部同時改了舊路徑的子分類，合併後舊路徑會冒回來，確認框的「外部改了」會列出，手動處理。

測試：`node scripts/test/prompt.mjs`（`window.__pe`，OPFS 假專案）。
