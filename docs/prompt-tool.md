# 提示詞（tools/prompt/）

殼的「提示詞」分頁。管理給 AI 生圖（裝備、道具…）用的提示詞，組好按「複製提示詞」貼到外面的 AI，**不打 API**。物品完全手動建，跟 `item.json` 無關。

## 檔案

- 頂端「檔案」框：相對專案根目錄的路徑，預設 `prompts/prompt.json`，記在 `localStorage` 的 `tools.prompt.path`；按「載入」或 Enter 換檔。
- 檔案不存在時問要不要建骨架（資料夾一起建）。
- 結構：

```json
{
  "items": { "武器": [ { "name": "鐵劍", "file": "sword-iron", "desc": "...", "common": "武器" } ], "護具": [], "道具": [] },
  "common": { "武器": "...", "護具": "...", "道具": "..." }
}
```

分類跟 common 名稱可自由增刪改名（中文 OK），common 不必跟分類一對一。`file` 是生圖要存成的檔名（不含副檔名，照 texture key 命名，如 `sword-iron`；護具是整套的基本名，部位後綴由紙娃娃加），網頁版 ChatGPT 不能指定下載檔名，所以範本裡請它用 Python 另存。

## 組合規則（`compose()`）

common 裡有 `{desc}`／`{name}`／`{file}` 就代換；沒有就是 `desc + '\n' + common`（空的那邊省略）。`file` 沒填時，common 裡含 `{file}` 的行整行拿掉。

## 畫面

- 左欄同一條清單：最上面是「⚙ 共用」組（標題 ＋ 新增共用，這組不能改名／刪除／拖進物品），下面接各分類；每組點標題摺疊、Alt＋點全部一起摺／展開（只記在記憶體，搜尋中全展開；摺起選到的那組會清除選擇）；底部按鈕是「＋ 新分類」；每列只顯示名稱（描述／內容不上清單）；搜尋同時篩物品跟共用（比對名稱跟描述／內容）。選到哪種，右欄就顯示哪種（`S.mode`），再點一次選到的就取消選擇。
- 物品：依分類分組；分類標題 ＋ 新增物品（`common` 預設帶同名 common）、✕ 刪除（非空要確認）、雙擊改名；物品可拖曳排序、可拖到別的分類（拖到分類標題＝放最後）；搜尋比對 name／desc。右欄 名稱、檔名（後面標 `.png`＋「複製檔名」複製 `file`（不含副檔名），空的停用；搜尋也比對）、共用下拉、描述、組合結果＋複製；名稱／檔名／描述打字時組合結果即時更新，離開欄位才進 undo。
- 共用：右欄 名稱（改名連物品引用一起改，同一步 undo）、內容、用到的物品（點了跳過去）。刪除不擋，用到的物品清單標 ⚠、下拉顯示「（遺失）」。

## 存檔

手動存（Ctrl+S）、undo/redo、殼分頁圓點、`BroadcastChannel` 廣播 `file`＝路徑。存前發現檔案被外部改過就三方合併（`obj.js` 的 `merge3`）：物品沒有 id，**以分類為單位**；common 以每一條為單位。

測試：`node scripts/test/prompt.mjs`（`window.__pe`，OPFS 假專案）。
