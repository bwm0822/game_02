拖曳空白處拉出變形框（可以多個），點框切換、拖框外小方塊調大小、Delete 刪框。拖控制點變形：Shift+拖曳框選點、Ctrl+拖曳取消選點（Shift／Ctrl+點也行）；拖點時按 Shift 只沿水平或垂直；方向鍵微調；Ctrl+Z／Ctrl+Y 退回／重做目前這框，退到底再按會拿掉框。框開始拖點之後要先「重設」才能改格數
亮綠（H 範圍內、S、V 夠高）直接挖掉；半透明的綠霧（S 同亮綠、alpha 跟 V 照上面）也一樣。再從這些像素往外長幾格，只挖連著的「寬鬆綠」（上面 HSV＋RGB 判斷）清綠邊；不透明的暗綠衣服隔著描邊不會被挖。按確定才存成共用參數（自動拆圖也用這組，設定分頁看得到）；已經拆好的零件不受影響
頭盔：
透明底、直立的單把武器。按確定才清除透明（alpha < 32）→ 丟掉雜點（比最大塊 1% 小的）→ 裁到剛好 → 縮放，零件疊在原圖上、原圖隱藏；x／y 是手的位置（遊戲單位），橘色十字是支點：拖十字＝圖跟著動、x／y 不動（改 ox／oy），按住 R 拖曳＝轉角度 a（只是預覽，存到 item 一律 a=0），拖武器本體＝改 x／y。取消＝撤掉這次自動，離開／Esc＝保留結果
透明底，左邊光頭、右邊頭髮（臉的位置是綠色的洞）。按確定才清除透明（alpha < 32）→ 移除綠色 → 丟掉雜點（比最大塊 1% 小的；勾「保留框內小塊」時大塊外接框裡的留下）→ 照重心在中線左右分成頭／頭髮（只有一邊有東西就全部當頭）、裁到剛好 → 縮放，頭髮疊在頭上面。存檔%（PNG 縮成原圖幾 %）、scale（遊戲的 scale）各自調，勾 🔗 連動時頭髮兩個都跟頭一樣（只能改頭），x／y 是遊戲單位，把頭髮拖到頭上對好；頭對身體的細調去試穿分頁。拆出來的頭、頭髮自動標 pool 的 頭／頭髮，「存到 pool…」存進 part.json（PNG 在 roles/parts，id 預設是零件名），再到角色編輯器挑；頭像在角色編輯器「由頭髮產生」
綠底整套：左上光頭（丟掉）、右上帽子（沒畫就略過）、左下衣服、右下鞋子（身體的位置是綠色的洞）。帽子的 不拆／前後片／挖除 跟頭盔一樣：洋紅色是後片或要挖掉的部分，拆完就不再顯示切線。按確定才清除透明（alpha < 32）→ 移除綠色 → 依中線取象限、只留自己的塊、裁到剛好 → 縮放，零件疊在原圖上（鞋子在下、衣服在中、帽子在上）、原圖隱藏，自動標 pool 的 帽子／衣服／鞋子。存檔%＝PNG 縮成原圖幾 %，scale／x／y 只改擺放（遊戲單位）；男女各一組 scale／x／y，照上方 男｜女 切換，存檔% 共用。「存到 pool…」存進 part.json（PNG 在 roles/parts，id 預設是零件名；帽子拆了就是 -front／-back），再到角色編輯器挑；藏頭髮在部位分頁勾
選「前後片」時頭盔上的洋紅色是後片（被頭蓋住），選「挖除」時是要挖成透明的部分：拖起點（青色十字）、改線的條件重新追線，拖頂點、點邊加點微調，拆的時候一起拆成 -front／-back（後片放到最底層；挖除只有 -front）；拆完就不再顯示切線，要調去前後片模式。按確定才清除透明（alpha < 32）→ 移除綠色 → 依中線取象限（左上的頭丟掉）、只留自己的塊、裁到剛好 → 縮放，零件疊在原圖上、原圖隱藏；拆完留在模式裡，改數字即時套用（存檔%＝PNG 縮成原圖幾 %，改了才重新縮放；scale＝遊戲的 equip.scale，跟 x／y 一樣只改擺放），x／y 是遊戲單位；女版只有 scale／x／y，存檔% 跟男版共用。用「縮放」模式拉零件改的是存檔%（等比）。一張圖只拆一次，選原圖或零件再進來可以繼續調；取消＝撤掉這次自動（刪零件、顯示原圖），離開／Esc＝保留結果
item：選一組自動拆的護具／武器零件（原圖、零件、前後片都算），照 equip.sprite 找 item。pool：所有右鍵標了 pool 部位的圖層。載入照遊戲的 PNG 反推存檔%（要重烤先問），整次一步 undo。這個模式裡照常可以點選、拖曳圖層。 女版是每個零件自己的（圖層右鍵「女版」新增／刪除，標 ♀）：存檔一定存男版基準，零件有女版才寫 f、沒有就刪 f；載入照 f 設定有沒有女版
拖曳畫在選取圖層上（那格直接換成這個顏色，不混色）；Alt+點吸取顏色（連 alpha）；Ctrl+Z／Ctrl+Y 一筆一筆退。有修補的圖層不能再縮放、變形，要先「清除修補」

—
洋紅色那塊：存成「前後片」時變成後片（被頭蓋住，最底層的「-back」層），其他留在前片；存成「挖除」時挖成透明、只有前片。切那塊的方法：「手繪」自己點頂點圍出來（線不清楚的頭髮用它，頭髮第一次進來預設手繪），閉合後一樣能拖頂點、點邊加點；「沿線」從起點（青色十字）往上、往左找輪廓線，沿著線切出右下那塊；「魔術棒」從起點往外擴散，碰到輪廓線或透明就停，閉運算填平寬度 ≤ 2 倍的縫，「下／右 N px」：選到的下緣／右緣往外 N px 內是透明就連中間的線一起選（先下後右），描外圈（裡面的洞一起選）。切換存成會帶切法：前後片＝沿線，挖除＝魔術棒＋下，之後可以手動改。輪廓線＝不透明、而且亮度 < 門檻；在畫布上移動，色塊跟 (R,G,B,A) 顯示游標底下的顏色；-／+ 一次調 1，按住連續調。線斷掉或被誤判時開「畫線」：左鍵塗的地方強制是線（洋紅）、Shift＋左鍵強制不是線（青色）、右鍵清掉標記，放開滑鼠重新計算，標記不改圖片。拖起點、改條件、畫線會重新計算（蓋掉手改的頂點）；拖頂點、點邊加點微調，Delete（游標在頂點上）或 Alt＋點頂點刪點；Ctrl+Z／Ctrl+Y 一步一步退。已經拆過的圖層再進來可以接著改；按「撤掉前後片」會刪掉前後片、原圖重新顯示
