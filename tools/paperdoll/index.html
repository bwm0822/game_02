頭盔：
透明底、直立的單把武器。按確定才清除透明（alpha < 32）→ 丟掉雜點（比最大塊 1% 小的）→ 裁到剛好 → 縮放，零件疊在原圖上、原圖隱藏；x／y 是手的位置（遊戲單位），橘色十字是支點：拖十字＝圖跟著動、x／y 不動（改 ox／oy），按住 R 拖曳＝轉角度 a（只是預覽，存到 item 一律 a=0），拖武器本體＝改 x／y。取消＝撤掉這次自動，離開／Esc＝保留結果
透明底，左邊光頭、右邊頭髮（臉的位置是綠色的洞）。按確定才清除透明（alpha < 32）→ 移除綠色 → 照重心在中線左右分成頭／頭髮（只有一邊有東西就全部當頭）、裁到剛好 → 縮放，頭髮疊在頭上面。存檔%（PNG 縮成原圖幾 %）、scale（遊戲的 scale）各自調，勾 🔗 連動時頭髮兩個都跟頭一樣（只能改頭），x／y 是遊戲單位，把頭髮拖到頭上對好；頭對身體的細調去試穿分頁。頭像＝頭＋頭髮照目前位置疊起來（用縮小前的圖），等比塞進 尺寸×尺寸 的 %（可以超過 100，超出的裁掉）。存到 role 可以選任何角色（依 kind 分組，⚠＝body 不是 body-*，存了會疊兩顆頭），沒有 head／hair 就新增，檔名預設 head-／hair-／portrait-<id>；存過的角色記在零件上，下次存／載入 role 先選它
選「前後片」時頭盔上的洋紅色是後片（被頭蓋住），選「挖除」時是要挖成透明的部分：拖起點（青色十字）、改線的條件重新追線，拖頂點、點邊加點微調，拆的時候一起拆成 -front／-back（後片放到最底層；挖除只有 -front）；拆完就不再顯示切線，要調去前後片模式。按確定才清除透明（alpha < 32）→ 移除綠色 → 依中線取象限（左上的頭丟掉）、只留自己的塊、裁到剛好 → 縮放，零件疊在原圖上、原圖隱藏；拆完留在模式裡，改數字即時套用（存檔%＝PNG 縮成原圖幾 %，改了才重新縮放；scale＝遊戲的 equip.scale，跟 x／y 一樣只改擺放），x／y 是遊戲單位；女版只有 scale／x／y，存檔% 跟男版共用。用「縮放」模式拉零件改的是存檔%（等比）。一張圖只拆一次，選原圖或零件再進來可以繼續調；取消＝撤掉這次自動（刪零件、顯示原圖），離開／Esc＝保留結果
拖曳畫在選取圖層上（那格直接換成這個顏色，不混色）；Alt+點吸取顏色（連 alpha）；Ctrl+Z／Ctrl+Y 一筆一筆退。有修補的圖層不能再縮放、變形，要先「清除修補」

洋紅色那塊：存成「前後片」時變成後片（被頭蓋住，最底層的「-back」層），其他留在前片；存成「挖除」時挖成透明、只有前片。切那塊的方法：「沿線」從起點（青色十字）往上、往左找輪廓線，沿著線切出右下那塊；「魔術棒」從起點往外擴散，碰到輪廓線或透明就停，閉運算填平寬度 ≤ 2 倍的縫，「下／右 N px」：選到的下緣／右緣往外 N px 內是透明就連中間的線一起選（先下後右），描外圈（裡面的洞一起選）。切換存成會帶切法：前後片＝沿線，挖除＝魔術棒＋下，之後可以手動改。輪廓線＝不透明、而且亮度 < 門檻；在畫布上移動，色塊跟 (R,G,B,A) 顯示游標底下的顏色；-／+ 一次調 1，按住連續調。線斷掉或被誤判時開「畫線」：左鍵塗的地方強制是線（洋紅）、Shift＋左鍵強制不是線（青色）、右鍵清掉標記，放開滑鼠重新計算，標記不改圖片。拖起點、改條件、畫線會重新計算（蓋掉手改的頂點）；拖頂點、點邊加點微調，Delete（游標在頂點上）或 Alt＋點頂點刪點；Ctrl+Z／Ctrl+Y 一步一步退。已經拆過的圖層再進來可以接著改；按「撤掉前後片」會刪掉前後片、原圖重新顯示
